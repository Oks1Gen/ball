# World1 remaining egg pet sketches v1

2026-11-09. User approved Forest Egg's five-pet direction and requested matching
concept sheets for every remaining World1 egg, with later user revisions.
Titles verified in `RojoTest/src/server/EggSigns.luau`: Frost Egg, Magma Egg,
Void Egg, Solar Crown Egg. The latter is the existing premium AdminEgg station.

## Shared art direction

Reference: `../../ForestEgg/concepts-v4/forest-egg-five-pets-v4.png`.
Exactly five pets per egg; one square cube combining head/body, small soft
bevels, flat faces and tiny feet, expressive glossy eyes, smooth plastic shading.
Distinct species and large secondary silhouettes; restrained rarity accents.
No leafy/floral accessories, tiny texture detail or complex layered equipment.
The approved Forest sheet is the local reference, not a permanent-standard write.

Each sheet uses 3 upper cells and 2 centered lower cells. Labels below are
conceptual rarity directions, not gameplay balance. No percentages are shown.

## Provenance and verification scope

Built-in ImageGen; exact prompts in `prompts.json`. User-reference inputs retained
in the ForestEgg concept directories. All new images are saved alongside this
file, earlier concepts remain intact. KB reused: Shape Language and Silhouette
Testing, roster test and Checklist; Chibi Character Rules in Practice, Checklist.
Explicit cube references override generic round-body advice.

All four 1536x1024 PNGs visually inspected: exactly five complete cube pets per
sheet, correct readable names/rarities, no clipped wings/tails/antlers, restrained
detail and coherent palettes. Source/copy hashes verified in `verification.json`.
Singularity's orbit crosses the lower body below its face; this is acceptable
for the silhouette sketch, but final 3D visibility would need checking.
Some birds/wings have a few broad lobes rather than a single primitive; this
retains the requested simple soft style without fine feather decoration.

Static sketches for user review. No 3D modeling, rear/side turnarounds, game-scale
readability, Studio lighting, animation or gameplay tested. No source code,
inventories, Update Log, permanent standard, commit, upload or publication changes.
