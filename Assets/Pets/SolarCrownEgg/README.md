# Solar Crown Egg

Five pets for Football City's fifth egg. The soft cube proportions, faces and
silhouettes follow the attached reference. The warm colors are saturated for
the simulator style. The rear views extend the reference's forms. All five
Blender scenes use a two-unit cube and a ground pivot. [Reference](reference.png)

The existing Celestial stand uses the standard hatch at 300,000 Wins per egg.
Restricted players receive Honey Bee. Glitched Dragon is the guaranteed Admin
Egg offer in Shop, using the existing Developer Product.
