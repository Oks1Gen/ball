# Trail shop icons

Ten separate icons generated with the built-in ImageGen tool on 2026-10-31,
in the requested order: Gale, Tidal, Volcanic, Electric, Frost, Earthquake,
Void, Cosmic, Rainbow, Divine. Each numbered PNG is 1024 by 1024 with real
RGBA transparency and at least 123 transparent pixels on every side.

Gale was the composition reference for the other nine individual requests.
All exports use one shared full-image scale and translation; no image was
cut out of a sheet. Original generated files remain untouched.

- `generation.json`: complete prompts and original generation paths.
- `source-bounds.json`: alpha bounds before export.
- `verification.json`: final dimensions, alpha bounds and padding checks.
- `trail-icons-1024.zip`: exactly the ten standalone PNGs.

The approved set was uploaded through Studio MCP and connected in
`RojoTest/src/client/UIAssets.luau` on 2026-10-31. `roblox-assets.json` records
the ten Image asset IDs and their existing saved trail IDs. The game itself
was not published.

The experience (universe `10770268214`) has Use access to all ten images;
`permissions.json` records ten successful grants with no errors. PC runtime
verification rendered the production trail-shop components with local preview
data, confirmed all ten images were ready, scrolling, close/reopen, larger
artwork and the trophy/text grouping. No purchase or reward remote was sent.
