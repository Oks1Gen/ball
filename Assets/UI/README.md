# Итоговые UI-ассеты

32 иконки созданы встроенным ImageGen **отдельными запросами**, по одному
предмету на прозрачном фоне. Каждый PNG — самостоятельное изображение
512×512; уменьшен весь исходный холст, без обрезки или нарезки.

Стиль: насыщенные контрастные цвета, толстая чёрная обводка, простая
мультяшная заливка, минимум бликов. Shop и Rebirth используют яркую фуксию
и голубой. Robux — белый знак с чёрной обводкой по образцу пользователя.
Камни в Trail-иконках заменены футбольными мячами.

`studs.png` — точная копия предоставленного пользователем файла
`RobloxGames/Assets/ui/studstandalone.png` (420×420), без изменения рисунка.
`burst.png` — отдельная прозрачная текстура лучей карточек наград, сохранена
из предыдущей реализации; это фон, не иконка и не фрагмент атласа.

- `prompts.json`: отдельный промпт и путь исходной генерации каждой иконки.
- `verification.json`: размеры, границы непрозрачной области и проверка краёв.
- `roblox-assets.json`: загруженные Roblox Image asset IDs.

Игра использует целые изображения, без ImageRectOffset/ImageRectSize.
Старые атласы в `RojoTest/generated-ui` — история; в новых иконках не используются.

`update-log.png` — отдельная иконка журнала обновлений, созданная встроенным
ImageGen 29.10.2026: голубой планшет с жёлтым зажимом и листом новостей.
Сохранён исходный прозрачный PNG 1254×1254, без обрезки; подробности и точный
промпт — `update-log.asset.json` и `prompts.json`. Roblox Image:
`106721086001751`. Используется в верхней панели и углу окна Update Log.

`sunburst.png` — исходная текстура пользователя, скопирована без изменений из
`RobloxGames/Assets/Textures/sunburst.png`; лучи Starter Pack.
Roblox Image `100836241976168`, источник — `sunburst.asset.json`.

## Карточки питомцев

`Pets/pet-inventory-v1.png` — утверждённая пользователем сетка 16 карточек,
сгенерированная по реальным моделям из Studio. Это отдельный запрос на
использование именно этих готовых карточек: они подключены как атлас 4×4,
исключение из прежнего подхода отдельных UI-иконок. Исходник 1254×1254 сохранён
без изменений; Roblox выдаёт 1024×1024. Image ID 123833931134956; ячейки
256×256, порядок — `client/Modules/PetCardArt.luau`. Названия и редкости
встроены в картинку, множитель и экипировка остаются игровыми элементами.
Метаданные — `Pets/pet-inventory-v1.asset.json`.

### Прозрачные иконки и английские подписи

Текущая версия — `Assets/UI/Pets/pet-inventory-v2-transparent.png`, Image ID
86854425517241. В исходнике есть настоящий alpha-канал; рамки, фон и встроенный
русский текст удалены ImageGen. Названия и редкости теперь рисуются живыми
английскими подписями из GameConfig в PetCardImage. Области отдельных силуэтов
(а не равномерные ячейки) заданы в PetCardArt: исходник 1254×1254, Roblox 1024×1024.
Предыдущий v1 сохранён для истории, в инвентаре не используется. Проверены PC
и iPhone 17 Pro LandscapeRight; полный check.mjs прошёл.

### Отдельные иконки v3

По уточнению пользователя все 16 петов заново созданы отдельными запросами
ImageGen. Каждый PNG в `Assets/UI/Pets/individual-v3/` — самостоятельный
оригинальный файл 1254×1254 с alpha, перенесён целиком без нарезки/обрезки.
`individual-v3-generation.json` хранит отдельные промпты и исходники,
`individual-v3-verification.json` — размеры и alpha. Атласы v1/v2 сохранены
только как история; инвентарь больше не использует ImageRectOffset/Size.
Каждый PetId получает свой Image ID через PetCardArt.image. Английские подписи
остаются живым текстом интерфейса. Декоративные лучи SelectionRays удалены
из предпросмотра, чтобы за питомцем не было полос/текстуры.

## Training Boost bubbles

`training-boost.asset.json` documents the native Roblox UI asset. Its reusable
React component is `RojoTest/src/client/Controllers/TrainingBoostBubble.luau`.
It uses the existing studs and Robux textures, five gradients and a rainbow
gradient with live outlined text. No new bitmap or Image asset upload is needed.
