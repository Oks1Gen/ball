# Локации FootballCourse

Источником границ являются восемь `Zones/Zone01…08/Field`, а не старые пять
секций FieldCorridor. Текущие поля имеют длину 270 studs; трасса идёт от
Z=124 до Z≈−2036. Длина трассы, поля, разметка и баланс удара не менялись.

| Зона | Тема | Диапазон Z | Цвет боковых стенок RGB |
| --- | --- | --- | --- |
| 01 | Palm Beach | 124…−146 | 176,124,63 |
| 02 | Desert Dunes | −146…−416 | 216,170,84 |
| 03 | Candy Beach | −416…−686 | 172,115,160 |
| 04 | Violet Valley | −686…−956 | 128,93,180 |
| 05 | Ember River | −956…−1226 | 166,83,47 |
| 06 | Moonlight | −1226…−1496 | 94,116,179 |
| 07 | Frozen Falls | −1496…−1766 | 143,190,210 |
| 08 | Rainbow Paradise | −1766…−2036 | 190,126,149 |

После `WorldLayout.apply` запускается `CourseRegions.apply`:

- Четыре берега каждой зоны получают отдельные косметические тела
  `Geometry/Banks/{InnerWest,InnerEast,OuterWest,OuterEast}`. Их центр и
  длина берутся из Field, ширина/верх — из четырёх BiomeBank; studs есть на
  вертикальных гранях. Смена цвета совпадает с полями и разделителями.
- Старые пятизонные GroundTile и рендер-слои скрыты; физические опоры
  сохранены с прежней геометрией и флагами. Неиспользуемые заменённые
  SurfaceSource-слои удаляет проверенный TransparentCleanup.
- Пять старых секций опор лежат в общей `Geometry/BankSupport/Section01…05`:
  они физически пересекают несколько нынешних зон. Нельзя выдавать целую
  секцию за одну игровую локацию или менять её коллизии ради покраски.
- WorldLayout распределяет отдельные модели деревьев, камней и кустов по
  фактическому положению, сохраняя обратный журнал для старых строителей.
  158 моделей природного декора получают текущую палитру из CoursePalette.
  Малые объекты, заходящие за границу, целиком сдвигаются внутрь с отступом
  1 stud, только если у них нет физических/query/touch частей. Крупные
  тематические композиции и финальная Sakura не перемещаются.
- `ZoneDividers.align` каждый раз рассчитывает 7 разделителей по соседним
  Field, ширину по берегам и оттенок по следующему полю. Название на каждой
  стороне указывает зону, в которую игрок войдёт с этой стороны.
- `Shared.WorldRefs.boundaries` — доступ к `FootballCourse/Boundaries`.
  Gameplay/ShotZones использует его для пересечений удара; старый путь
  `arena.ZoneDividers` в игровой логике недопустим.

Первопричина: пять исторических секций по 384 studs и их палитра продолжали
рисоваться поверх восьми игровых зон по 270 studs. Простая перекраска
старых больших деталей оставляет переходы внутри соседних локаций.

Проверка `tools/VerifyCourseRegions.luau` выполняется в Edit и Server после
штатного Play: 32 берега, 28 пар стыков, 160 лучей к реальной опоре, полные
модели декора внутри своей зоны, 7 последовательных переходов удара в Play.
Проверка коллизий не включает скрытые камни/деревья в лучи к полу:
они проверяются отдельно сохранением исходных физических объёмов.
Повторный apply не пересоздаёт берега и не сдвигает декор ещё раз.
