# Стенды рейтингов

Оформление `LobbyRankings.style(map)` применяется после организации карты в
WorldService. Оно обновляет существующие четыре стенда, сохраняя размещение,
исходный корпус и пути `Panel.RankingGui`. Повторный вызов пропускает стенды
с текущей версией `RankingStyle=4`; прежний декор обновляется на месте.

Корпус — яркий мультяшный пластик: голубой Skill, жёлтый Wins, фиолетовый
Best Throw, розовый Донат. Толстые тёмные края, ровные объёмные шапки,
выступающие угловые блоки и ступенчатые опоры меняют силуэт. Шапки и верхние/
нижние угловые блоки выровнены по корпусу, без наклона. Сверху круглые
медальоны с существующими игровыми иконками Skill/Wins/Ball/Robux из UIAssets.
Декор `CartoonTrim` содержит 19 деталей на стенд. Неон и источники света не
используются. Studs используют существующую текстуру карты 88156646156237
с шагом тайла 8 studs; верхние грани также имеют SurfaceType.Studs.
Заголовки — крупные белые GothamBlack с тёмной обводкой. Строки светлые,
номера на цветных плашках; первые три места выделены золотом, серебром и бронзой.
Таблица разделена на Rank, Entry и Value: длинные имена обрезаются внутри своей
колонки, результаты выровнены справа. Четвёртый стенд остаётся заглушкой.
SurfaceGui использует фиксированный холст 620×745 и LightInfluence=0.

Проверено 2026-10-28: полный `node RojoTest/tools/check.mjs` прошёл (69 Lune,
5 Node-тестов, форматирование, Selene, Rojo build, типы без новых находок).
В Studio Play проверены четыре стенда по 10 строк, отсутствие неона,
идемпотентность оформления, загрузка всех четырёх иконок (Client IsLoaded=true),
рендер длинного имени и большого результата через временные данные только
для отображения; профильные значения не подменялись. Временные данные и
Play удалены после проверки. В Output осталось известное предупреждение
Rojo об ассете 203785492, ошибок игрового кода не обнаружено.
