# Разделение поверхностей карты

Аудит 2026-10-28 охватывает оба мира `Workspace.Map`, а не только World1.
`tools/CheckSurfaceOverlaps.luau` проверяет параллельные открытые грани блоков
и клиньев с допуском 0.035 studs. Учитываются поворот деталей, площадь пересечения
и перекрытие третьими непрозрачными блоками. Пространственный индекс ускоряет
проверку скрытых граней; обработка уступает управление пакетами.
Боковые грани клиньев консервативно ограничены прямоугольником. Внутренние
треугольники MeshPart, сфер и цилиндров этот геометрический аудит не проверяет.
Дополнительная проверка точных дублей MeshPart по MeshId/CFrame/Size дала 0.

Начальный аудит: 7 204 близкие открытые грани. После исправлений: 0 в Edit.
Повторный запуск Play: 17 676 проверенных блоков/клиньев, 0 пар. Отдельно
учтён декор магазина мячей World2, создающийся при запуске игры.

## Исправления

- FootballPitches разносит газон, полосы, линии, центральное пятно и сегменты
  окружности по отдельным высотам. Коллизия исходного поля не меняется;
  разметка не имеет коллизий. Устранены 14 устаревших записей baseline об
  обязательном седьмом аргументе `part`: новый выбор слоя устранил эту находку.
- SurfaceSeparation применяется последним в WorldService к обоим мирам.
  В SurfaceSeparationData — 2 532 измеренных косметических исправления;
  порядок записей определяет сохранённые SurfaceSeparationId, менять его нельзя.
  Селектор содержит путь родителя, имя, исходные позицию и размер. При повторных
  именах родителей проверяются все совпадающие ветви. Несовпавшая геометрия
  пропускается с предупреждением, а не меняется наугад.
- Для каждого исправления создаётся отдельная видимая копия в папке
  `WorldN.SurfaceSeparation`. Меняются только размеры и локальное смещение
  этой копии. Теги, скрипты, интерактивные объекты, свет и GUI не дублируются.
  Исходная деталь скрывается вместе с Texture/Decal. CFrame, Size и флаги
  CanCollide/CanTouch/CanQuery оригинала сохраняются. Это проверено численно
  и при полном повторном создании слоя в Play. Повторное apply идемпотентно.

## Откат и обслуживание

Копия содержит ObjectValue `OriginalPart`. Исходная прозрачность детали и её
Texture/Decal хранится в атрибуте `SurfaceSeparationTransparency`. Для отката
восстановить эти значения, удалить SurfaceSeparationId/SurfaceSeparationTransparency
у оригиналов и удалить только папку SurfaceSeparation. Сам исходник не удалять.
После ручного изменения геометрии повторять аудит; статический план не должен
автоматически адаптировать неизвестные новые детали.

Selene без замечаний, Rojo build, типы без новых/устаревших находок. В Play
ошибок игрового кода нет; осталось известное предупреждение Rojo об ассете
203785492. После проверки Studio возвращена в Edit. Сцену не публиковали.
