# Посадка декора лобби

Этот проход описывает прежнюю посадку растений. По новой просьбе пользователя
свободный декор лобби удалён, см. [lobby-composition.md](lobby-composition.md).
LobbySceneCleanup остаётся совместимым с историческими входами и вызывается
до LobbyDecorRemoval; растения в готовую сцену не возвращаются.

03.11.2026 `server/LobbySceneCleanup.luau` исправляет готовую сцену после
WorldLayout, финального оформления и CloudSea, перед TransparentCleanup.
В Edit применяется только этот узкий проход: старые строители и prepare не запускаются.

- Пересажены 279 цветов: неподдержанные растения с прежних координат террас
  и цветы, полностью или частично пересекавшие кусты/камни. Новое место выбирается
  на существующем газоне той же высоты с проверкой всей геометрии цветка,
  соседних растений и декора. Исходные CFrame сохранены в BeforeLobbyGrounding.
- Обрезанные старым SurfaceSeparation лепестки и сердцевины восстанавливаются
  по исходному рецепту SpawnGarden; добавлена отсутствующая часть одного цветка.
- Все пять частей сундука отодвинуты вместе от стойки карты. Физика не меняется.
- Удалены девять частей подвески, потерявшей крепление после снятия арки,
  отдельный лепесток без растения и связанный скрытый оригинал: 11 BasePart.
  Их записи WorldLayout удалены, SurfaceSeparation IDs выведены из восстановления.
  ExplorerOutpost больше не создаёт старую подвеску.

Взаимные соединения частей деревьев, кустов, камней и цветов остаются намеренными.
Функциональные опоры, свет, цели и точки покупки не считаются мусором.
Перенос травяных площадок, яиц, рейтингов и игровой геометрии не выполняется.

`tools/VerifyLobbySceneCleanup.luau` независимо строит граф контактов OBB
с допуском 0.08 stud до неподвижных физических опор. Учитываются визуальные
берега курса под фонарями входа; анимированные мячи/яйца исключены.
Edit и обычный Server Play: 7585 деталей, 0 оторванных компонентов.
Проверяются также отсутствие новых пересадок, правок сундука, удалений и
восстановлений при повторном проходе. Цветы не пересекают консервативные
объёмы кустов/камней; для клиновидных камней проверка использует полный габарит.

Численные проверки не заменяют просмотр изображения. Общий вид, вход,
террасы и стенд сохранены в `.tools/lobby-cleanup-2026-11-03/` вместе с
локальными журналами исходных положений. Независимый visual-critic: 6/6
в пределах показанных ракурсов. Итоговые проверки — [verification.md](verification.md).
