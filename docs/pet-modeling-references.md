# Pet model reference catalog

Current library: [Assets/Pets/README.md](../Assets/Pets/README.md).
Machine-readable names, rarities, status and sheet paths:
[catalog.json](../Assets/Pets/catalog.json).

Ten eggs, five pets each: World1 Forest/Frost/Magma/Void/Solar Crown and World2
Kelp/Leviathan/Treasure/Abyss/Jelly. Fifty model concepts total.

User requirements preserved for future modeling: one square cube as combined
head/body for every pet, small soft bevels, expressive eyes, tiny feet, minimal
decoration, rarity expressed by silhouette and restrained material accents.
World2 palette was revised to bright saturated colors; its current references
are `Assets/Pets/World2/concepts-v2/`, except Treasure's current v3 sheet in
`Assets/Pets/World2/concepts-v3/` (Ruby Koi replaces rejected Treasure Mimic).
Pastel v1 is superseded.
Forest's current five-pet reference is v4, approved by the user. Frost uses the
user's attached sheet for proportions and the later saturated palette for art.
Magma's latest sheet is `World1/remaining-eggs-v2/magma-egg-five-pets-v2.png`,
with saturated simulator colors and the original five silhouettes preserved.
Its [five-model library](../Assets/Pets/MagmaEgg/README.md) is now integrated
in Studio, including all five matching 24 px outlined UI portraits.
The [Void Egg library](../Assets/Pets/VoidEgg/README.md) contains the attached
reference, five Studio models and five matching outlined portraits.
The [Solar Crown Egg library](../Assets/Pets/SolarCrownEgg/README.md) completes
the five World1 rosters with five editable models and five outlined portraits.
The World2 sheets are available for review.

All PNGs, original user images and exact built-in ImageGen prompts are retained
inside the project. Existing Git LFS PNG rules apply; `.gitignore` allows this
library to be included in a future authorized backup. No commit/push performed.

The sheets show one concept angle per pet. All five Forest Egg pets have
editable Blender models and GLB/FBX exports. Their paths are indexed in
catalog.json and [the asset library](../Assets/Pets/README.md). All five have
Studio imports and outlined UI portraits, including Clover Bunny and Acorn Squirrel.
See [the Roblox assets](../RojoTest/assets/pets/forest-v1/roblox-assets.json).

The [Frost Egg model library](../Assets/Pets/FrostEgg/README.md) has the five
Studio-verified models and their 24 px outlined portraits.
