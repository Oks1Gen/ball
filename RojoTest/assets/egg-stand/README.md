# Egg stand — approved arc concept

Current editable Blender model: connected five-bay stand **without eggs**, at the user's request. Gray studded body, charcoal foot, colored octagonal seats and center steps retained. No turf. Prepared as an asset; not installed in Studio or released in the game. Previous complete version is preserved in `egg-stand-with-eggs.blend` and the earlier full exports.

- `egg-stand.blend`: current empty stand, separate front/top cameras and presentation collection. The original default Blender scene is preserved separately.
- `stand-only.glb`: current empty stand with embedded palette.
- `stand-only-validation.json`: current geometry check, zero eggs, 34 meshes, 3,928 triangles; closed geometry with no degenerate faces.
- `egg-stand-with-eggs.fbx`: stand and five eggs, embedded palette. Includes named separate meshes; excludes floor, cameras and lights.
- `stand-only.fbx`: stand without eggs, for use with the existing interactive game eggs.
- `egg-stand-with-eggs.glb`: same complete asset with embedded palette.
- `palette.png`: fallback color texture; keep next to the FBX.
- `preview-front.png`, `preview-top.png`: actual Blender renders.
- `build_stand.py`: procedural source. Creates a new scene; `INCLUDE_EGGS=False` produces the current empty stand. Original egg sources remain available for the optional complete version.
- `validation.json`: mesh/UV checks and FBX round-trip report.

## Scale and placement

One Blender unit represents **5 Roblox studs**. Authoring axes: X across display, -Y toward players, Z up. Asset width is approximately 24.2 Blender units / 121 studs; depth approximately 26.5 studs. A Studio 3D Importer unit setting can change the resulting scale: verify the imported width, rather than relying on a fixed importer default. Scene origin is at ground level directly under the central egg. For Roblox, map Blender -X to world +X and Blender +Y to world +Z to match the measured egg row.

Read-only Studio measurements used: Common (103.8, 276), Uncommon (79.8, 280.8), Volcanic (55.4, 283.2), Rare (31, 280.8), Rainbow (7, 276), X/Z studs. Existing plaza: center (55, 20.28, 279.2), dimensions 131.2 x 0.2 x 41.6 studs. Current asset uses offsets from the central egg; fit and collisions still need checking after an authorized import. Full egg height in this asset is 2.85 units / 14.25 studs.

Use **stand-only.fbx** when placing in the real game so the five existing interactive eggs and their prompts/logic can be retained. For a complete isolated display, use the full FBX. Import with textures enabled and verify scale, separate hierarchy and collision proxies before replacing any existing object. No upload or game publication has been performed.
