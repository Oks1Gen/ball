# Ball authoring sources

The current ten-ball Low Poly V2 pack lives in `Assets/Balls/LowPolyV2/`
at the repository root. Its Blender scene, scripts, reference images, atlas,
exports and Roblox asset IDs are versioned there.

No runtime mapping or mesh ID changed during cleanup.

The replaced first-generation pack, intermediate Blender snapshots and old
exports were removed from this directory on 2026-11-03. They remain available
in backup commit `a010fd2` with their original README and generation scripts.
