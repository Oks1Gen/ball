# Elemental eggs

Final editable source: **elemental-eggs-final.blend**. Approved reference:
reference.png. Actual final Blender render: preview-refined.png.

The five models are already imported in the connected Roblox Studio at
`ServerStorage.Assets.Eggs.Elemental`. Use those 105 optimized native unions for
placement; the mapped `.rbxmx` is a heavier reproducible facet input.
`ElementalPreviewRow` holds spaced copies outside Workspace for convenient review.

For mesh-based importing use **elemental-eggs.fbx** with textures enabled;
palette.png is embedded and provided beside it. Five named model roots, 105
component meshes, 4,394 triangles, UVs and flat shading. No preview floor/camera
is included in FBX/GLB. Each model is 10 units high; verify importer scale against
the existing 10-stud egg visual and normalize pivot to the ground origin.

Full import procedure, persistence limitation, integration notes and verification:
`../../../../docs/elemental-eggs.md`.
